```bash
pip install pyyaml

```

## لماذا هذه البنية

صفحات `src/reference/` **مشتقّة بالكامل** من `language-truth/`، ولذلك لا تُودَع في
git (انظر [`.gitignore`](../.gitignore)). النسخةُ المودَعةُ لمشتقٍّ تنجرف عن أصلها
حتمًا — وقد حدث مرّتين (القضيّتان #1 و#8). فما الذي يحرس المولّد إذن؟

الحارسُ القديم كان `gen_reference.py --check`: يقارن مخرج المولّد بصفحاتٍ ولّدها
المولّدُ نفسه من مصدرٍ **متحرّك**. طرفاه من أصلٍ واحد ⇒ لو انحدر المولّد ثمّ أُعيد
التوليد، مرّ أخضرَ وانتشر الانحدار إلى الصفحات المنشورة.

هنا الطرف الأوّل **مجمَّد**:

| المجلّد | المحتوى |
|---|---|
| `fixtures/sot-<قناة>-<sha>/language-truth/` | لقطة SoT مجمَّدة عند إيداعٍ بعينه |
| `golden/<قناة>/*.md` | المخرج المتوقَّع للمولّد على تلك اللقطة |

فالمقيس هو **المولّد وحده**. والقناتان (`sadlang` و`dev`) مُغطّاتان معًا لأنّ
`deploy.yml` يبني الاثنتين.

## تحديث الذهبيّ

عمدًا فقط، ويُراجَع في الـPR سطرًا سطرًا:

```bash
python scripts/gen_reference.py \
  --source-dir tests/fixtures/sot-dev-1138f5e1 --source-ref dev \
  --out-dir tests/golden/dev
```

## تحديث اللقطة المجمَّدة

اللقطة قديمة **عمدًا** — قِدَمها لا يضرّ، لأنّها تقيس المولّد لا اللغة. حدّثها فقط
إن أضاف SoT شكلَ بياناتٍ جديدًا يجب أن يغطّيه المولّد:

1. انسخ `keywords.yaml`, `operators.yaml`, `types.yaml`, `ui_props.yaml` من الإيداع
   المطلوب إلى `fixtures/sot-<قناة>-<sha-جديد>/language-truth/`.
2. احذف مجلّد اللقطة القديم، وحدّث `CHANNELS` في `test_gen_reference.py`.
3. أعِد توليد الذهبيّ، وراجع الخلاف في الـPR.

## حارس الجذاذة (`--verify`)

`VerifyGuardTest` يغطّي حارسًا ثانيًا مستقلًّا عن الذهبيّ:
`python scripts/gen_reference.py --verify` يقرأ القرص وحده (بلا SoT ولا شبكة) ويتحقّق
أنّ الصفحات الأربع مُولَّدةٌ فعلًا. سببه واقعةٌ **مقيسة**: صفحةٌ مذكورةٌ في `SUMMARY.md`
وملفُّها غائب لا تُفشل `mdbook build` — بل يُنشئ mdBook جذاذةً من العنوان وحده
(٣٢ بايتًا) ويبني بنجاح (خروج 0). فلولا الحارس لنشر `deploy.yml` أربع صفحاتٍ بيضاء
بصمت. يسبق الحارسُ `mdbook build` في `ci.yml` و`deploy.yml`، ويعمل ذاتيًّا بعد كلّ توليد.

> جُرّب مُعالِج mdBook (preprocessor) لهذا الغرض أوّلًا — يعمل في كلّ بناءٍ بنسخةٍ
> واحدة — فأعطى سلوكًا غيرَ حتميٍّ على ويندوز (stdin يصل فارغًا أحيانًا). حارسٌ
> يمرّ أحيانًا ليس حارسًا، فاختير المسار الحتميّ.

## حرّاس على الاختبار نفسه

`GuardTest` يمنع الأخضر الكاذب: سجلّ صفحاتٍ فارغ، أو ذهبيٌّ فارغ، أو لقطتان
متطابقتان تجعل «مصفوفة القناتين» وهمًا.
