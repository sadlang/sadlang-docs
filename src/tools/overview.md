# أدوات لغة ص — نظرة عامّة

تأتي لغة ص بطقم أدوات سطر أوامر متكامل يغطّي دورة العمل كلّها: التشغيل، الترجمة،
إدارة الحزم، التنسيق، والفحص الساكن. كلّ أداة ثنائيّ مستقلّ يخرج من بناء المستودع
نفسه، وكثير من الرايات له **مرادف عربيّ** إلى جانب الإنجليزيّ.

| الأداة | الدور | الصفحة |
|---|---|---|
| `sad-run` | **المفسّر** — تنفيذ ملفّات `.ص` مباشرةً | [التشغيل والترجمة](run-build.md) |
| `sad-build` | **المترجم** — ترجمة `.ص` إلى ملفّ تنفيذيّ أصليّ (LLVM) | [التشغيل والترجمة](run-build.md) |
| `sad-pkg` | **مدير الحزم** — تثبيت الاعتماديّات ونشر الحزم | [مدير الحزم](package-manager.md) |
| `sad-fmt` | **المنسّق** — تنسيق الشيفرة تلقائيًّا وفق أسلوب موحَّد | [الجودة](quality.md) |
| `sad-check` | **الفاحص الساكن** — فحص الملكيّة والأنواع دون تشغيل | [الجودة](quality.md) |
| `sad-lsp` | **خادم اللغة** — إكمال وتشخيص داخل المحرّرات (بروتوكول LSP) | [الجودة](quality.md#خادم-اللغة-sad-lsp) |

> **المحرّكان متكافئان سلوكيًّا**: البرنامج الواحد يعطي المخرجات نفسها مفسَّرًا
> (`sad-run`) ومُترجَمًا (`sad-build`) — تحرسه بوّابة مطابقة آليّة في كلّ تغيير.

## أوّل تشغيل

```text
sad-run برنامجي.ص          # تنفيذ فوريّ بالمفسّر
sad-build برنامجي.ص -o برنامجي   # ترجمة إلى تنفيذيّ أصليّ
./برنامجي                   # تشغيل الناتج المُترجَم (على Windows: .\برنامجي.exe)
```

## أين أجد الأدوات؟

بعد بناء المستودع تجدها في `build/bin/Release/` (والمنسّق `python x.py build`
يثبّت **المحرّكين** `sad-run`/`sad-build` تحديدًا في `dist/<Config>/`).
راجع [التثبيت والتشغيل](../getting-started/setup.md).
