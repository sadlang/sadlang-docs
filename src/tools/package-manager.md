# مدير الحزم: `sad-pkg` و`sad-build pkg`

طريقان لإدارة الحزم: الأداة المستقلّة `sad-pkg` (الكاملة)، وتكامل مدير الحزم داخل
المترجم `sad-build pkg` (الأوامر الأساسيّة بأسماء عربيّة). تعرض مساعدة التكامل
الاسم التاريخيّ `sadc` — وهو نفسه الثنائيّ `sad-build`.

## الأداة المستقلّة `sad-pkg`

### أوامر المشروع

| الأمر | المعنى |
|---|---|
| `init` | إنشاء حزمة جديدة (ملفّ تعريف الحزمة) |
| `install [حزمة]` | تثبيت الاعتماديّات (أو حزمة بعينها) |
| `add <حزمة> [إصدار]` | إضافة اعتماديّة |
| `remove <حزمة>` (أو `rm`) | إزالة اعتماديّة |
| `update` (أو `upgrade`) | تحديث الاعتماديّات كلّها |
| `list` (أو `ls`) | سرد المثبَّت |
| `verify` | التحقّق من سلامة المثبَّت |

### أوامر السجلّ

| الأمر | المعنى |
|---|---|
| `search <نصّ>` | البحث في السجلّ المركزيّ |
| `info <حزمة>` | معلومات حزمة |
| `publish [--local]` | نشر حزمة (يتطلّب رمز نشر — انظر أدناه) |

### أوامر مساعدة

| الأمر | المعنى |
|---|---|
| `config <مفتاح> [قيمة]` | قراءة/ضبط الإعدادات (المفتاحان: `registry` و`token`) |
| `doctor` | تشخيص البيئة |
| `clean` | تنظيف الخبيئة |

## عنوان السجلّ المركزيّ

الافتراضيّ `https://sila-hub.dev` (عبر HTTPS). ويمكن تغييره بثلاث طبقات، الأعلى
أسبقيّةً أوّلًا:

> 🚧 **القناة القادمة:** قراءة `sad-pkg` لمتغيّر البيئة `SAD_REGISTRY_URL`
> (الطبقة 1) متوفّرة في القناة القادمة (`/next/`) وتنتقل إلى المستقرّ مع الإصدار
> التالي. أمّا `sad-build pkg` فيقرؤه في المستقرّ أيضًا، والطبقتان 2 و3 مستقرّتان.

1. **متغيّر البيئة** `SAD_REGISTRY_URL` — الأنسب للتجارب وبيئات CI:

   ```text
   SAD_REGISTRY_URL=http://localhost:3000 sad-pkg search رياضيات
   ```

   (صيغة السطر أعلاه لصدفات POSIX؛ في PowerShell:
   `$env:SAD_REGISTRY_URL = "http://localhost:3000"` ثمّ نفّذ الأمر.)

2. **الإعداد الدائم** عبر `config`:

   ```text
   sad-pkg config registry https://سجلّي-الخاصّ.example
   ```

3. **الافتراضيّ** المضمَّن في الأداة.

### النشر ورمز الاعتماد

النشر إلى السجلّ يتطلّب رمزًا (token) يُضبط مرّة واحدة:

```text
sad-pkg config token <الرمز>
sad-pkg publish
```

> ⚠️ لا تضع الرمز في ملفّات المشروع أو سكربتاته المتتبَّعة — يُقرأ من الإعداد
> المحلّيّ (خارج المستودع) أو من متغيّر البيئة `SAD_TOKEN` في CI.

## تكامل المترجم `sad-build pkg`

الأوامر الأساسيّة نفسها من داخل المترجم، وبأسماء عربيّة:

| الأمر | المرادف العربيّ | المعنى |
|---|---|---|
| `install <حزمة>` | `تثبيت` | تثبيت من السجلّ المركزيّ (مع `--version <إصدار>` اختياريًّا) |
| `list` | `سرد` | سرد المثبَّت محلّيًّا |
| `sync` | `مزامنة` | مزامنة الحزم من ملفّ `sad.toml` |
| `search <نصّ>` | `بحث` | البحث في السجلّ |

```text
sad-build pkg تثبيت شبكة-http
sad-build pkg install sad-math --version 1.2.0
sad-build pkg سرد
sad-build pkg مزامنة
```

ويحترم `sad-build pkg` متغيّر البيئة `SAD_REGISTRY_URL` نفسه لتجاوز عنوان السجلّ.

## أين تُخزَّن الحزم؟

- **حزم المشروع**: في مجلّد `حزم/` داخل المشروع (لكلّ حزمة ملفّ تعريف
  `package.json` أو `حزمة.صم` ومصادرها).
- **الخبيئة العامّة**: في مجلّد بيانات المستخدم (`sad-lang/cache`) — نظّفها بـ`sad-pkg clean`.
